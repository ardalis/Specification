# Ardalis.Specification

**IMPORTANT** This is the last MIT-licensed release of this library. Future releases will require a (potentially free) commercial license. [Find out more](https://nimbletools.io/news/ardalis-nuget-packages/)

A .NET library for building query specifications, compatible with EF6, EF Core, and Repository abstractions.

The usage guide and the documentation can be found [here](https://specification.ardalis.com/).

The change log for version 9 and the list of breaking changes can be found [here](https://github.com/ardalis/Specification/issues/427).
